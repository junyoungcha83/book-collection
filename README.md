# 도서모음

읽은 책을 정리하는 개인용 PWA. 데이터는 **기기(localStorage)** 에 저장됩니다.

## 기능
- **홈**: 책을 그리드로 표시, `＋ 책 추가` 타일
- **추가**: 제목·저자를 입력하면 홈에 카드로 표시
- **상세(5탭)**: 목차 / 내용 / **원본** / 내용요약 / 메모 — 모두 수기 입력, 자동 저장
  - **서식**: 진하게 · 정렬 · 글자 크기 · **글자색** · **음영(형광펜)** — `적용: 선택/전체` 로 고른 글자만 또는 탭 전체에 적용, 음영은 끝의 사선 스위치로 지움
  - **본문 삽화**: 하단 툴바의 `🖼️ 그림` · `▦ 표` 로 **커서가 있는 문단 바로 뒤**에 그림/표 삽입(원본 탭 제외)
  - 그림을 탭하면 크기(작게/중간/크게/꽉) · 배치(글 왼쪽·가운데·글 오른쪽, 좌우는 글이 옆으로 흐름) · 캡션 · 삭제
  - 표 안에 커서를 두면 ＋행/－행/＋열/－열 · 제목행 · 표 삭제
  - 사진 **붙여넣기**도 커서 자리에 바로 삽입, 업로드 이미지는 자동 축소
  - **워드(.docx) 불러오기**: 문단 서식 + 표 + 그림을 **원래 있던 자리 그대로** 본문에 넣음
  - 하단 **그림 보관함**은 예전 방식(별도 업로드)으로 남아 있고, `↥ 본문으로` 로 본문에 옮길 수 있음
- **원본 탭(글자 전용)**: 책의 원문을 그대로 담는 곳. 붙여넣기·끌어다 놓기 모두 **서식 없이 글자만** 들어가고, 그림·표 넣기 버튼은 이 탭에서 숨겨집니다.
  - **텍스트(.txt) 불러오기**: UTF-8 이 아니면 **EUC-KR(CP949)** 로 자동 재해석 — 옛 한글 txt 도 깨지지 않음
  - 이미 글이 있으면 확인 후 **뒤에 이어 붙이기**, 줄바꿈과 줄 앞 들여쓰기는 그대로 보존

## 구조
```
index.html
assets/app.js     그리드·상세·탭·저장·이미지
assets/app.css    민트 테마
assets/icon.svg   아이콘(민트 배경 + 흰 책 + '도서모음')

sw.js             오프라인 캐시
```

## 동기화 (여러 기기)
- 백엔드: **Cloudflare Worker + KV** (`api/`), 단일 키 `doso-data`에 전체 JSON 저장.
- 엔드포인트: `GET /api/data`(읽기, 누구나) · `PUT /api/data`(쓰기, `X-Edit-Token` 필요).
- 앱 우상단 **🔒/🔓** 로 동기화 비밀번호 입력 → 편집 내용이 서버에 저장되고 다른 기기에서도 보임.
- 비밀번호 없이도 읽기(로컬 전용)는 동작.

## 읽기 / 편집 모드
비밀번호(권한)와 편집 **모드**는 다르다. 비밀번호를 넣어 뒀어도 평소에는 읽기 상태라,
글을 읽다가 실수로 지우거나 고칠 수 없다. **📝 편집** 을 눌러야 편집이 켜지고, **✅ 완료** 로 끈다.

- 편집 모드는 저장하지 않는다 — 앱을 새로 열거나, 책을 열거나, 홈으로 나가면 항상 읽기부터.
- 꺼져 있으면 글상자가 잠기고 ＋타일·정보수정·삭제·서식바·그림바가 모두 감춰진다.
- 켜져 있으면 글상자에 옅은 테두리가 생겨 지금 고칠 수 있는 상태임이 보인다.
- 비밀번호가 없으면 편집 버튼 자체가 안 보인다(자물쇠부터 눌러야 한다).

### 언제 맞추나
- **올리기**: 편집할 때마다(0.8초 디바운스).
- **내려받기**: 앱을 열 때 + **화면으로 돌아올 때**(`visibilitychange`) + 온라인 복귀 때.
  앱을 껐다 켜야만 반영되던 문제가 여기서 났었다 — 예전엔 `DOMContentLoaded` 때 한 번뿐이었다.
  단, 편집기에 커서가 있으면 입력이 튀므로 그때는 건너뛴다.
- **🔄 새로고침**(홈 화면 상단): 손으로 당겨 받는다. 일부러 누른 것이므로 편집 중이어도 받아온다
  (내 수정은 `updated_at` 이 최신이라 병합에서 살아남는다).

### 버전 표시
홈 화면 제목 옆에 `v12` 처럼 뜬다(`APP_VER`). 폰에서 새 버전이 실제로 적용됐는지 눈으로 확인하려는 것.
**배포할 때 세 곳을 같이 올린다**: `assets/app.js` 의 `APP_VER` · `sw.js` 의 `CACHE` · `index.html` 의 `?v=`.
안 맞추면 서비스워커가 옛 파일을 계속 내줘서 폰에 반영이 안 된다.

### 한쪽 수정이 다른 쪽을 덮지 않게
전체 문서를 통째로 덮어쓰면 한 기기의 작업이 통째로 날아간다. 그래서:
- 책마다 `updated_at` 을 두고 **책 단위로 최신 것**을 고른다 → 서로 다른 책을 고쳤으면 둘 다 산다.
- 삭제는 목록에서 빼지 않고 `deleted` 표시만 남긴다 → 다른 기기에서 되살아나지 않는다.
- 서버가 `rev` 를 세고, 앱은 `X-Base-Rev` 로 "내가 본 판"을 같이 보낸다.
  그 사이 다른 기기가 저장했으면 **409 + 최신본**을 돌려주고, 앱이 합쳐서 한 번 다시 올린다.
- 같은 책을 양쪽에서 고쳐 한쪽이 밀리면 밀린 본을 `doso-books-backup` 에 남기고 알린다.

### 서버 준비(최초 1회)
```
cd api
npx wrangler kv namespace create BOOKS   # id 를 wrangler.toml 에 반영
npx wrangler deploy
npx wrangler secret put EDIT_TOKEN        # 동기화 비밀번호 설정(대화형)
```

## 참고
- 저장은 서버(KV) + 기기 localStorage 캐시. 그림을 많이 넣으면 용량이 커질 수 있어요(업로드 시 자동 축소).
- 동시 편집은 마지막 저장이 우선(last-write-wins)입니다.
